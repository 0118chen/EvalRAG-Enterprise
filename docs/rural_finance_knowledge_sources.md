# 农村贷款与农村金融公开资料清单

用途：建立面向农村贷款、农户贷款、小额贷款公司和涉农金融业务的知识库。

下载原则：

- P0 为第一批必须下载的现行核心资料。
- P1 为农村金融、担保、土地和消费者保护补充资料。
- P2 为地方规定或历史试点资料，建议单独建立版本标签，避免与现行规则混用。
- 优先下载官方网站的 HTML、PDF、DOC 或 DOCX 原文，并记录发布日期和施行日期。
- 同一制度有修订版本时，只将最新版放主知识库；旧版放入“历史版本”目录。

## 建议下载顺序

1. 先下载 P0 的贷款规则和小额贷款公司监管规则。
2. 再下载民法典、农村土地承包法、农业法、乡村振兴促进法和农村集体经济组织法。
3. 然后下载 P1 的担保、征信、消费者保护和数据合规文件。
4. 地方资料只在确认中信农和实际展业省市后，再按地区、版本和发布日期补充。

建议文件命名：

```text
层级_发布机关_文件名_发布年份_版本状态.pdf
```

例如：

```text
P0_国家金融监督管理总局_个人贷款管理办法_2024_现行.pdf
P0_国家金融监督管理总局_小额贷款公司监督管理暂行办法_2025_现行.pdf
P1_农业农村部_农村土地经营权流转管理办法_2021_现行.pdf
```
